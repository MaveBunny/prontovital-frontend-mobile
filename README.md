Aplicativo mobile do projeto Prontovital, desenvolvido com React Native, Expo e TypeScript (utilizando Expo Router).

Pré-requisitos
Node.js (LTS recomendado)
npm
Aplicativo Expo Go no celular ou emulador Android/iOS
Como executar
Instale as dependências:

npm install
Inicie o servidor de desenvolvimento:

npm start
Scripts úteis:

npm run android — abre no emulador/dispositivo Android
npm run ios — abre no simulador iOS (macOS)
npm run web — executa no navegador
npm run lint — executa a verificação de lint do Expo
npm run reset-project — move os arquivos de exemplo para example/ e cria um src/app limpo
Estrutura inicial
src/app/ — rotas baseadas em arquivos (Expo Router)
assets/ — ícones, splash screen e imagens
app.json — configurações do Expo
